# ComplexSystemWebsite

A modern landing page for a deep-tech company focused on AI, robotics, and space systems.

## GitHub Pages

This site is configured to publish automatically to GitHub Pages using the workflow in [.github/workflows/deploy-pages.yml](.github/workflows/deploy-pages.yml).

## Preview locally

Open [index.html](index.html) in a browser, or run:

```bash
python3 -m http.server 3000
```
